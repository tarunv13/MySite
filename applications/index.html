Three things this dossier cannot give you

  • No PI names CORDIS does not publish principal investigator names in its bulk export — there is no such column in project.csv or organization.csv. Institutions are complete; the person is not. You get the name from the project's CORDIS page or the group's own site, one at a time.
  • No Erasmus, at all Erasmus+ and Erasmus Mundus Joint Masters are a separate programme from Horizon Europe and appear nowhere in CORDIS — every one of the 223 records and every scheme code was searched, with zero matches. Erasmus Mundus catalogues live on the EACEA Joint Masters listing and the Erasmus+ Project Results platform, which are different sources needing their own fetcher.
  • No application deadlines Deadlines belong to the calls layer, which is down — the SEDIA API has been answering 500 to every request since at least 27 Jul 2026. Everything here is a grant with a start and end date, not an opening with a closing date. Every date below is a project date; closing dates must come from the institution's own vacancy page.
